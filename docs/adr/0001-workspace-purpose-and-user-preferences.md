# 保留完整工作空间定位，以日常知识工作和用户设置为先

2026-09-26 设计访谈 Q1–Q3 确认：Companion 保留完整沉浸工作空间定位，包括 One Field、空间布局和阅读行为，不收缩为纯阅读修补插件；Kami Reader 保留独立主题价值。阅读、编辑、查阅和双 pane 对照的日常效率优先于单篇文章的展示效果，文章化空间处理应放在显式进入的 Reading Stage 中。Kami 提供默认视觉，用户显式修改的设置在普通模式和 Reading Stage 中都应继续有效；接受由此产生的默认风格差异，不通过模式切换恢复固定的宽度、背景或强调色。

该决策修订旧交接文档中 Companion 固定拥有 700px 正文尺度及自身色板的约束，保留已确认的 One Field 方向。当前实现尚未按本决策调整；后续确认见 ADR 0002，本记录不表示实施或发布已获授权。
