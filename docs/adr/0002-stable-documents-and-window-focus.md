# 文档排版稳定，专注状态跟随窗口工作过程

2026-09-26 设计访谈 Q4–Q7 确认：所有 Markdown pane 保持稳定排版，活动焦点切换只改变活动标识、Outline 跟随及显式 Focus 下的强调，不改变标题字号、正文宽度或间距；阅读与编辑的必要差异保留。普通模式和 Reading Stage 均取消自动导语、READING NOTE 及修改日期装饰，文件名与正文 H1 保留原生关系，避免把任意笔记解释成文章。取消非活动 pane 的整体透明度降低，Focus 内容强调仅作用于当前文档并保持周边文字可读，以保护多文档查阅和对照。

Focus 是每个窗口内的临时工作状态：切换 Markdown 文件、pane 或阅读／编辑模式继续生效；进入非 Markdown 视图暂停文档强调，回到 Markdown 恢复；明确关闭、Escape 或重启结束。Reading Stage 和白纸预览继续绑定当前文档，不向新文档转移。

这取代旧交接文档中的活动文档专属排版、自动文章装饰、目标切换即清理 Focus 及参考 pane 整体降透明度的设计。代价是默认展示效果更克制，并需区分窗口的专注意图与当前文档强调；收益是内容语义和对照工作保持稳定。当前仅确认设计，尚未修改实现或授权发布。
