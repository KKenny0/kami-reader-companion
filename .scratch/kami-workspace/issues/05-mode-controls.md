# 05: 在原生文档菜单发现、查看和退出模式

**What to build:** 用户通过现有文档菜单或原有命令控制 Stage、Focus 和白纸预览，始终能知道当前状态并直接退出。

**Blocked by:** 04：Focus 跟随窗口工作过程，参考文档保持可读

**Status:** done

**范围与工作量：** Companion，中等；复用原生命令与文档菜单，不新增 Ribbon 按钮、默认快捷键或自建菜单框架。

- [x] 三种模式在现有文档菜单中集中出现并显示实际选中状态，与命令操作实时一致。
- [x] Stage 仅阅读态可用；其他模式遵守 Markdown 目标条件，不可用项不产生无效状态。
- [x] 模式开启后有简短可操作的状态提示，支持指针和键盘直接退出；组合模式可分别退出。
- [x] 状态提示不挤坏窄 pane 页头、不改变正文排版；菜单／弹窗优先处理 Escape，不吞掉原生导航按键。
- [x] 切换目标、暂停和恢复 Focus、多窗口、卸载后菜单与提示无陈旧状态或残留节点。
- [x] 保留可运行的状态一致性检查，并提供命令、菜单和键盘退出的真实应用演示。

本地实施与 macOS 复审完成；证据见 [第二轮复审报告](../../../docs/workspace-phase2-review.md)。双平台正式候选验收留在 07。
