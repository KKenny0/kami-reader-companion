# 07: 完成双平台候选验收并落实发布门禁

**What to build:** 为组合后的候选版本提供 macOS 与 Windows 当前资产的真实行为和像素证据，缺少任一必需平台证据时不能被标记为验收通过。

**Blocked by:** 01：切换 pane 时保持文档排版与语义稳定、02：主题设置在 Companion 与 Stage 中持续生效、03：窄 pane 保持读写密度，宽内容局部展开、04：Focus 跟随窗口工作过程，参考文档保持可读、05：在原生文档菜单发现、查看和退出模式、06：滚动定位不重复测量未变化的宽内容

**Status:** ready-for-agent

**范围与工作量：** 两个仓库，中等偏高；包括现有视觉证据检查和发布门禁更新，不执行公开发布。

- [ ] 两平台分别覆盖 Default + Companion 与 Kami Reader + Companion、浅色与深色；主题独立使用补做设置与窄 pane 回归。
- [ ] 核验设置继承、双 pane 稳定、窄 pane 密度、Focus 生命周期、多窗口、模式入口与退出、Stage、白纸预览、长文宽内容和键盘可达性。
- [ ] 所有截图仅使用合成笔记；记录应用版本、平台、配套主题与插件资产指纹及人工审查结果，历史截图不计入。
- [ ] 更新现有检查器与发布门禁：缺少 Windows 或 macOS 当前证据、资产不匹配、场景缺失时失败；保留配套主题来源绑定，不绕过已有审查。
- [ ] 两仓库自动检查通过，视觉检查指向实际配套候选主题；未来发布流程取用的主题必须与审查资产一致，不沿用旧主题资产冒充新验收。
- [ ] Windows 环境不可用时明确保持本项未完成；Linux 仍注明未实机验收，Companion 保持桌面限定。
- [ ] 更新用户说明和验收记录，说明模式生命周期与设置继承；不创建标签、Release 或修改商店条目。
