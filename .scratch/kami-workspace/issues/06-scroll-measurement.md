# 06: 滚动定位不重复测量未变化的宽内容

**What to build:** 长文滚动继续准确更新 Outline，同时避免重复测量未变化的宽内容；真正的内容与尺寸变化仍及时适配。

**Blocked by:** None (can start immediately)

**Status:** done

**范围与工作量：** Companion，中等；复用现有调度，区分滚动定位与内容尺寸失效，不增加缓存框架。

- [x] 在渲染内容与尺寸均未变化时，纯滚动不触发宽内容全量测量；Outline 仍准确响应上下滚动。
- [x] 虚拟化生成新内容、图片加载、内容尺寸变化和 pane 调整后仍触发必要测量，不能把“滚动中出现新内容”误判为无变化。
- [x] 多 pane／多窗口不因单 pane 滚动而全量扫描；关闭和卸载取消待处理回调与观察器。
- [x] Outline 映射不可靠时继续原生回退；不改变笔记内容或用户布局。
- [x] 使用同一合成长文、视口与滚动操作记录修改前后的测量次数和主线程耗时，附可重跑方法；不预先宣称卡顿或虚构提速百分比。
- [x] 添加能在纯滚动意外恢复全量测量时失败的回归检查，并验证必要失效事件没有遗漏。
